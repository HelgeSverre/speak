// Letter-to-sound rules in the NRL scheme (Elovitz et al. 1976), written for this project.
// left [graphemes] right = phones
// #  one or more vowels      :  zero or more consonants    ^  one consonant
// .  a voiced consonant      %  suffix e er es ed ing ely  +  front vowel e i y
// $  word boundary
// Within a letter the first matching rule wins; each list ends with a context-free default.
// Vowels are written unreduced: stress assignment turns unstressed AH ER IH into AX AXR IX.
