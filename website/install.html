Install

One command gives you speak and speak-lab. No data files to download, no model to fetch.

  • macOS, Apple Silicon and Intel
  • Linux, arm64 and x86_64
  • 3.9 MB binary

  1. Install with Homebrew

    From the helgesverre/tap tap. Works the same with Homebrew on Linux.

    brew install helgesverre/tap/speak

  2. Say something

    The flags are those of macOS say. Docs has the rest.

    speak "Hello world."
speak -v '?'
speak -v klatt-pip --sing=twinkle

Other ways

Install script

Downloads the binaries for your platform from the latest release into ~/.cargo/bin.

curl --proto '=https' --tlsv1.2 -LsSf https://github.com/HelgeSverre/speak/releases/latest/download/speak-installer.sh | sh

From source

Needs Rust; the repository pins 1.99 and rustup fetches it on the first build. On Linux, install libasound2-dev first.

git clone https://github.com/HelgeSverre/speak
cd speak
cargo install --path .

Extras

All optional. speak works without any of them.

Pronunciation dictionary

The CMU Pronouncing Dictionary, 126,000 words, fetched at a pinned revision and checksum-verified. Without it, words outside the built-in lexicon go through the letter-to-sound tree.

speak-lab lexicon build "$(curl -fsSL https://raw.githubusercontent.com/HelgeSverre/speak/main/scripts/fetch-cmudict.sh | sh | tail -1)"

Diphone voice

The second backend: 2,013 diphones analysed from the formant synthesizer, built in about 12 seconds.

speak-lab diphones build --bootstrap
speak -b diphone "Hello."

Coding agents

An MCP server on stdio with speak and list_voices tools, so an agent can talk to you.

claude mcp add --scope user speak -- speak --mcp

SidePulse strip

Plug in a SidePulse Pro and speak shows a mouth on its eight LEDs while it talks. Nothing to configure.

speak --no-lights "Not now."

Defaults

Voice, rate and named voices in a config file. See Files.

rate = 190

[klatt]
voice = "klatt-female"

This website

Builds the engine to WebAssembly with wasm-pack and serves it locally.

Uninstall

Removes both binaries. Voices and the dictionary live in ~/Library/Application Support/speak on macOS, config in ~/.config/speak.

brew uninstall speak

Installed with the script or from source: cargo uninstall speak.
