speak

Offline text-to-speech by formant synthesis, written in Rust. It takes the same flags as macOS say.

New here? Start with Install.

Usage

speak "Hello world."
speak -v klatt-drama -r 150 "To deploy, or not to deploy?"
echo 'Dr. Smith paid $3.50 on 12/03/2024 at 5pm.' | speak -o receipt.wav
speak -f chapter.txt --progress

Text comes from arguments, -f file or standard input. Ctrl-C stops at once and still leaves a valid output file.

Options

From say

OptionDescription
-v voiceVoice name, backend:voice or a config alias. -v '?' lists voices.
-r wpmWords per minute, 80 to 500. Default 175.
-o fileWrite audio instead of playing. The extension picks the format: .wav, .aiff, .raw. Default AIFF. - is stdout.
--file-format=fmtWAVE, AIFF or raw.
--data-format=fmt[BE|LE][I|F][16|24|32][@rate], for example LEF32@48000. Default 16-bit at 16000 Hz.
--channels n1 or 2.
-a deviceOutput device by name or index. -a '?' lists devices.
-f fileRead text from a file. - is stdin.
--progressProgress on stderr.

Voice parameters

Pass with -P key=value, or as params in a config alias. Out-of-range values are rejected.

KeyRangeDescription

Diphone backend: excitation=glottal|pulse|residual. Both backends: lts=cart|rules picks the letter-to-sound method.

Embedded commands

Written inside the text, as in say.

CommandEffect
[[slnc 500]]Silence in milliseconds
[[rate 300]]Words per minute from here on
[[volm 0.5]]Volume from here on
[[pbas 140]]Base pitch in Hz from here on
[[inpt PHON]]ARPAbet input until [[inpt TEXT]]
 
speak "Wait for it. [[slnc 800]] [[rate 320]] And now very fast."

Files

~/.config/speak/config.toml

Defaults and voice aliases. Command line beats environment beats config.

rate = 190
lights = true

[klatt]
voice = "klatt-female"

[audio]
device = "MacBook Pro Speakers"

[voices.narrator]
voice = "klatt-calm"
rate = 160
params = { range = 1.4, breath = 20 }

~/.config/speak/lexicon.txt

Your own pronunciations. They override every other source.

kubectl K Y UW1 B K AH2 T AX L
nginx EH1 N JH IH0 N EH1 K S

Environment: SPEAK_VOICE, SPEAK_BACKEND, and SPEAK_LIGHTS=0 to turn the strip off.

Pipeline

Normalizer, chunker, lexicon and letter-to-sound, prosody, rule compiler, formant renderer. --dump stops at any stage.

speak --dump text 'Dr. Smith paid $3.50 on 12/03/2024 at 5pm.'
# doctor Smith paid three dollars fifty on december third twenty twenty four at five p m.

speak --dump phonemes 'Hello world.'
# HH AX L OW1 / W ER1 L D .

speak --dump chunks 'Hi there. How are you?'
# 0  .  Hi there.
# 1  ?  How are you?

--dump pho gives each phone, its duration in milliseconds and pitch targets as percent and Hz:

; chunk 0  "Hello."
HH   59
AX   33  0 119  100 116
L    74  0 116  100 120
OW1  268  0 120  30 125  100 78
_    60

The same format is accepted as input. | also ends a line, so a whole file fits on one command line:

speak --phonemes=pho -f hello.pho
speak --phonemes=pho "HH 59 | AX 33 0 119 100 116 | L 74 0 116 100 120 | OW1 268 0 120 100 78 | _ 60"

Agents (MCP)

speak --mcp serves the Model Context Protocol on stdio, so a coding agent can talk to you.

claude mcp add --scope user speak -- speak --mcp
{ "mcpServers": { "speak": { "command": "speak", "args": ["--mcp"] } } }
ToolArguments
speaktext, and optionally voice, rate, pitch, sing, file. Returns when speech ends, or writes file.
list_voicesNone

Calls queue in order. Cancelling a request stops its audio. Set a default voice with SPEAK_VOICE in the server's environment.

SidePulse

With a SidePulse LED strip mounted, speak shows a mouth on its eight LEDs in sync with the audio: wide and warm on open vowels, narrow and cool on closed ones, dark when the lips close. The previous LED state comes back afterwards. Without a strip nothing changes. --no-lights, lights = false or SPEAK_LIGHTS=0 turn it off.

Browser build

The home page runs the formant synthesizer compiled to WebAssembly, 1.9 MB. CMUdict, user lexicons and the diphone backend need files and are not in it.
